# Orbit Switch

A one-tap arcade game: switch orbits, dodge blocks, beat bosses.

**Play:** https://akullar19.github.io/orbit-switch/

## Install on your phone
- **iPhone:** open the link in Safari → Share → **Add to Home Screen**.
- **Android:** open it in Chrome → ⋮ → **Add to Home screen** / **Install app**.

It then runs full-screen like an app and works offline after the first launch. Your progress is saved on your own device.
